# Apify actors: name search and LinkedIn, created 14:30

Last updated: 2026-11-13 14:30. Store data read from the public API the same day. Prices are pay-per-event list prices for the free and bronze tiers unless stated; the account's own tier may be cheaper (measured costs below). Monthly runs are the last 30 days from the store stats. ## Category 1: name to web search

- apify/google-search-scraper, https://apify.com/apify/google-search-scraper. Official Google SERP scraper (search result page scraper). Price 0.0045 USD per result page on the free tier, 0.0025 on bronze, plus 0.00005 start; add-ons optional. No login or cookie. 9.6M runs in 30 days, 136M total, 0.2 percent failed or timed out at most 2 percent. Input: queries (required, one per line, supports quoted names), maxPagesPerQuery, countryCode, languageCode, site, plus many filters and add-ons. Tested yes. 30 s wall time, 1 item (one item per query page, results nested under organicResults), cost 0.002 USD measured. Item fields: searchQuery, url, organicResults, peopleAlsoAsk, relatedQueries, paidResults, paidProducts, suggestedResults, hasNextPage, htmlSnapshotUrl, serpProviderCode. The operator's LinkedIn profile appears among the results but not as the first result (the first result is some other page).
- igolaizola/google-search-scraper-ppe, https://apify.com/igolaizola/google-search-scraper-ppe. Cheap SERP scraper returning position, title, url, snippet. Price 0.0003 per result on free tier (0.00015 bronze) plus 0.001 start (0.0005 bronze); about 0.0013 for a one-name query. No login. 179k runs in 30 days, 5.6M total. Input: query (required), maxItems (required), country, language, domain, timeRange, proxyCountry. Tested yes. 8 s, 10 items, cost 0.0037 USD measured (10 results). Item fields: position, title, url, snippet. The operator's LinkedIn URL was not in these 10 results, so recall for a plain quoted name was worse than the official actor; adding "linkedin" to the query was not tested.
- s-r/free-google-search-results-serp---only-0-25-per-1-000-results, https://apify.com/s-r/free-google-search-results-serp---only-0-25-per-1-000-results. Very cheap SERP scraper. Price 0.00035 per result. No login. 12k runs in 30 days (126k total), 3 percent failed. Input: queries (required), country, cr, maxResults. Tested no. Fallback if cost matters; low usage and little other evidence.
- Also seen, not shortlisted: scrape.badger/google-search-scraper (0.001 per fast page, 18k runs in 30 days), apidojo and epctex versions.

## Category 2: LinkedIn search by name

- harvestapi/linkedin-profile-search-by-name, https://apify.com/harvestapi/linkedin-profile-search-by-name. Finds profiles from first and last name with optional filters (locations, currentCompanies, pastCompanies, schools, currentJobTitles). Price per search page 0.004 (Short mode returns the search page only; "Full" adds 0.004 per profile, "Full + email" 0.01). No cookie or login. 2.4M runs in 30 days, 11.7M total, 6 percent timed out. Input: profileScraperMode (required: Short, Full, Full + email search), firstName, lastName, strictSearch (exact name match), maxPages, locations, currentCompanies, pastCompanies, schools, currentJobTitles, industryIds, maxItems. Tested yes (Short, maxItems 5, not strict). 3 s, 1 item, cost 0.004 USD measured. Item fields: id, linkedinUrl, location, name, photo, position, publicIdentifier. The operator's profile was the first result. No explicit confidence score; the signal is name match plus rank, so the app should compare against the company or location the attendee gave.
- apimaestro/linkedin-profile-search-scraper, https://apify.com/apimaestro/linkedin-profile-search-scraper. Name search that returns full profile data per result. Price 0.005 per result on free to gold tiers (0.003 diamond). No login. 20.5k runs in 30 days, 824k total, very low failure. Input: firstname, lastname, max_profiles, location, current_job_title, include_email. Tested yes. 15 s, 1 item, cost 0.005 USD measured. Item fields: basic_info, education, experience, languages, projects, search_criteria, volunteering-experiences. The operator was the first result. One call gives both the match and a full profile, but it is about five times slower than the harvestapi search and returns no explicit profile URL field name in the top-level keys (probably inside basic_info; not checked).
- scrapeverse/linkedin-user-profile-url---mass-finder, https://apify.com/scrapeverse/linkedin-user-profile-url---mass-finder. Batch name to profile URL finder. Price 0.006 per result free tier (0.004 gold), plus 0.00005 start. No login. 1.2k runs in 30 days, 86k total. Input: names (required), country, resultsPerPagPerQuery, page, matchExactword. Tested no. Cheap and batchable but low recent usage.
- Also seen, not shortlisted: harvestapi/linkedin-profile-search (0.10 per search page, built for filtered lead lists, too costly for single names), endspec/linkedin-instant-profile-search (0.007 per profile, 800 runs in 30 days).

## Category 3: LinkedIn profile read

- harvestapi/linkedin-profile-scraper, https://apify.com/harvestapi/linkedin-profile-scraper. The current choice. Price 0.004 per profile (0.0022 diamond), 0.01 with email. No login. 8.4M runs in 30 days, 44M total, under 0.1 percent failed. Input: profileScraperMode, queries, urls, publicIdentifiers, profileIds. Tested no (already in use). Nothing found that is clearly better: the alternatives seen are either the same developer's search actors (which return the same data) or lower-usage actors. Switch not recommended.

## Recommended chains

- Only a name. Step 1: harvestapi/linkedin-profile-search-by-name in Short mode with firstName, lastName and any given company as currentCompanies (0.004). Step 2: pick the top result when name and company or location agree, then read it with harvestapi/linkedin-profile-scraper (0.004) by publicIdentifier. Step 3 in parallel for non-LinkedIn context: igolaizola/google-search-scraper-ppe with the quoted name plus "linkedin" or the company, maxItems 10 (about 0.004), or apify/google-search-scraper for better recall (about 0.002 to 0.0045). Cost per person about 0.008 for LinkedIn only, about 0.012 to 0.017 with a web search. Time about 3 s search plus the profile read (not timed here; run in parallel with the web search) plus 8 to 30 s for the web search, so about 15 to 35 s per person, less when people run in parallel.
- Name plus LinkedIn URL. Skip search: harvestapi/linkedin-profile-scraper by URL (0.004). Optional web search as above only for extra context (about 0.002 to 0.004). Cost per person 0.004 to 0.008. Time bounded by the profile read, not timed here; the web search adds 8 to 30 s if run in parallel.
- Shortcut if one call must do it: apimaestro/linkedin-profile-search-scraper returns match plus full profile for about 0.005 in about 15 s, but with max_profiles above 1 it bills every result.
